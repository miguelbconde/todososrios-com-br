# Encaminhamento para todososrios.com.br

Página que leva ao site do Todos os Rios, cujo endereço principal é https://todososrios.com.br/ (repositório principal: miguelbconde/todososrios).

Até 23/11/2026, este repositório atendia pelo todososrios.com.br e encaminhava para o endereço provisório do GitHub. Nesse dia o .com.br passou a ser o endereço principal e foi para o repositório principal. Quando o registro do todososrios.rio sair, este repositório passa a atender por ele (arquivo CNAME com `todososrios.rio`), encaminhando para o .com.br.
